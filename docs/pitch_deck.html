AssemblyAI Voice Agent Hackathon 2026

VoxDive

Talk to any video or podcast — out loud.

Paste a link. VoxDive transcribes, diarizes, and chapters it with AssemblyAI, then lets you have a spoken conversation with the content — answers grounded only in what was actually said, cited by timestamp.

Akmal Khan · @akmalkhaniub
The problem

Spoken content is a black box.

Billions

of hours of podcasts, talks, and videos — searchable only by title, not by what was said.

Scrubbing

To find one claim at minute 34, you drag a timeline and hope. There's no "ask the video."

Hallucination

Chatbots over transcripts confidently invent answers the recording never contained.

We want to ask long-form audio questions — and trust the answer.

The solution

VoxDive: a voice agent grounded in the transcript.

1

Ingest & understand — async AssemblyAI STT + speaker diarization + auto-chapters + entity detection. You get a diarized transcript, an outline, and a summary automatically.

2

Summarize & answer — LeMUR (Claude-powered) writes the summary and answers questions from the transcript.

3

Talk to it — the Voice Agent API turns it into a spoken conversation with turn-detection and barge-in. Every answer flows through a search_transcript tool, so it can't answer beyond the recording.

Ask about something the video never mentions → it says so, instead of making it up.

How it works

The whole AssemblyAI stack, chained.

Media URL ─▶ POST /v2/transcript ─▶ diarized segments · auto-chapters · entities
                                └─▶ LeMUR /lemur/v3/generate/task ─▶ summary + Q&A
                                            │
              VideoContext (IDF-weighted retrieval, timestamped, refuses to over-answer)
                                            │
        Voice Agent API  wss://agents.assemblyai.com/v1/ws
          tools: search_transcript · get_summary · jump_to_topic
          turn detection + barge-in · audio in (16k) ↔ audio out (24k)
                                            │
                          Web UI: chapters · transcript · voice + text chat · latency HUD

STT + diarization + chapters + entities + LeMUR + Voice Agent — one product, not one feature.

Why it's different

Grounding through tools, not vibes.

Trustworthy by construction

Answers come from a tool that returns real passages with timestamps. No passage, no claim.

Uses the full platform

Most entries use one AssemblyAI feature. VoxDive chains six into a single flow.

Zero-setup demo

Universally relatable

A judge pastes their own favorite video and talks to it. No domain expertise required.
